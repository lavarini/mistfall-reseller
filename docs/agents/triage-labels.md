# Rótulos de triagem

| Papel canônico | Rótulo no GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer precisa avaliar |
| `needs-info` | `needs-info` | Aguardando informação do reporter |
| `ready-for-agent` | `ready-for-agent` | Especificada e pronta para agente AFK |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será implementada |

Cada issue triada deve ter exatamente um rótulo de categoria (`bug` ou
`enhancement`) e um rótulo de estado desta tabela.
