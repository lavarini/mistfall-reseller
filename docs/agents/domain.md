# Documentação de domínio

Este é um repositório de contexto único.

Antes de explorar ou alterar o projeto, leia:

- `CONTEXT.md`, na raiz, para o glossário e as regras de domínio;
- os ADRs relevantes em `docs/adr/` para as decisões arquiteturais.

Use nos artefatos o vocabulário definido em `CONTEXT.md` e evite os sinônimos que o
glossário rejeita. Se uma proposta contradisser um ADR, sinalize o conflito
explicitamente em vez de sobrescrever silenciosamente a decisão.
